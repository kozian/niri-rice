# Горячие клавиши

В сеансе niri физическая Command работает как Ctrl, физический Ctrl — как Super,
а Option — как Alt
и основной модификатор `Mod`. `Option+/` открывает подсказку niri. Полный список настроен в [config.kdl](../.config/niri/config.kdl).

| Клавиши | Действие |
|---|---|
| Alt+Enter | Foot |
| Alt+Space / XF86LaunchB | Лаунчер Fuzzel |
| XF86LaunchA | Обзор окон и рабочих пространств |
| Ctrl+Space | Сменить раскладку EN ↔ RU |
| `Ctrl+\` | Показать или скрыть Waybar |
| Alt+B / E | Firefox / Thunar |
| Alt+Q | Закрыть окно |
| Alt+←/→, H | Перейти к соседней колонке. H работает как ← |
| Alt+↑/↓, K/J | Перейти между окнами в колонке |
| Alt+Shift+←/→ | Переместить колонку |
| Alt+Shift+↑/↓ | Переместить окно в колонке |
| Alt+Shift+, / Alt+. | Взять окно справа в колонку / вынести нижнее окно из колонки |
| Alt+R | Цикл ширины колонки ⅓, ½ и ⅔ |
| Alt+− / = | Изменить ширину колонки |
| Alt+Shift+− / = | Изменить высоту окна |
| Alt+F / Alt+Shift+V | Полноэкранный / плавающий режим |
| Alt+1…5 | Перейти к именованному рабочему пространству |
| Alt+Shift+1…5 | Переместить окно на именованное пространство |
| Alt+PgUp/PgDn или Alt+колесо | Перейти к предыдущему / следующему пространству |
| Alt+Shift+PgUp/PgDn | Переместить окно на соседнее пространство |
| Alt+L | Заблокировать экран |
| Alt+Escape | Меню питания |
| Alt+Shift+Q | Выйти из niri с подтверждением |
| Alt+N / Shift+N | Центр уведомлений / режим «Не беспокоить» |
| Alt+Shift+C | История буфера обмена |
| Alt+Shift+S | Интерфейс снимка области или экрана |
| Alt+Shift+P | Снимок активного окна |
| Print | Снимок текущего выхода. На MacBook может потребоваться внешняя клавиатура |
| Alt+Shift+T | Переключить Tokyo Night ↔ Catppuccin |
| Alt+/ | Подсказка по клавишам |

niri сохраняет снимки в `~/Pictures/Screenshots/` и помещает их в буфер обмена.
Поддерживаются стандартные жесты niri. Горизонтальный свайп тремя пальцами
прокручивает колонки, вертикальный переключает пространства. Удерживайте
Alt при перетаскивании левой кнопкой, чтобы переместить окно, или
правой, чтобы изменить его размер. Дополнительное
пространство создаётся по мере использования, а быстрые клавиши 1–5
привязаны к стабильным именам. [Жесты niri](https://github.com/niri-wm/niri/wiki/Gestures)

Клавиши XF86 управляют яркостью дисплея, громкостью (шаг 5%, максимум
100%), выключением звука/микрофона и MPRIS-воспроизведением. Их раскладка
на ряду F1–F12 зависит от режима Fn и драйвера. На клавиатурах Apple
PgUp/PgDn часто соответствуют Fn+↑/↓. Для устойчивых сочетаний
между раскладками проверьте фактическую карту на устройстве.

## Сочетания в приложениях

XKB меняет местами левые и правые пары Command и Ctrl внутри niri.
На подключённых клавиатурах то же происходит с Win и Ctrl. [Опции XKB](https://man.archlinux.org/man/xkeyboard-config-2.7.en)

- **Thunar:** ⌘+C/X/V работают с выбранными файлами, ⌘+Z отменяет
  файловую операцию, ⌘+W закрывает вкладку, ⌘+T открывает вкладку,
  ⌘+Q закрывает окно, ⌘+, открывает настройки. При обновлении установщик
  заменяет прежние Super-привязки для управляемых действий и сохраняет
  остальные записи. [Действия Thunar](https://github.com/xfce-mirror/thunar/blob/master/thunar/thunar-window.c)
- **Foot:** ⌘+⇧+C/V копируют выделение и вставляют текст, ⌘+⇧+N открывает
  новый терминал. ⌘+C обычно прерывает команду, а ⌘+W и ⌘+T
  передаются запущенной программе как Ctrl+W и Ctrl+T.
  [Конфигурация Foot](https://man.archlinux.org/man/foot.ini.5.en)
- **Firefox:** ⌘+C/X/Z/V и ⌘+W/T/Q используют штатные сочетания Firefox
  под Linux. Для действий с настраиваемыми сочетаниями доступен
  `about:keyboard`. [Справка Mozilla](https://support.mozilla.org/en-US/kb/customize-keyboard-shortcuts-firefox)

`Ctrl+Space` и `Ctrl+\` перехватывает niri. На MacBook
эти сочетания набираются через физическую Command. Сочетания Alt из таблицы также
доступны композитору, например Alt+←/→ переключает колонки при фокусе
на браузере.
