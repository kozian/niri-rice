# Горячие клавиши

Super — Command на клавиатуре MacBook. `Super+/` открывает подсказку
niri. Полный список настроен в [config.kdl](../.config/niri/config.kdl).

| Клавиши | Действие |
|---|---|
| Super+Enter | Foot |
| Alt+Space | Лаунчер Fuzzel |
| Super+Space | Сменить раскладку EN ↔ RU |
| `Super+\` | Показать или скрыть Waybar |
| Super+B / E | Firefox / Thunar |
| Super+Q | Закрыть окно |
| Super+←/→, H | Перейти к соседней колонке. H работает как ← |
| Super+↑/↓, K/J | Перейти между окнами в колонке |
| Super+Shift+←/→ | Переместить колонку |
| Super+Shift+↑/↓ | Переместить окно в колонке |
| Super+Shift+, / Super+. | Взять окно справа в колонку / вынести нижнее окно из колонки |
| Super+R | Цикл ширины колонки ⅓, ½ и ⅔ |
| Super+− / = | Изменить ширину колонки |
| Super+Shift+− / = | Изменить высоту окна |
| Super+F / Super+Shift+V | Полноэкранный / плавающий режим |
| Super+1…5 | Перейти к именованному рабочему пространству |
| Super+Shift+1…5 | Переместить окно на именованное пространство |
| Super+PgUp/PgDn или Super+колесо | Перейти к предыдущему / следующему пространству |
| Super+Shift+PgUp/PgDn | Переместить окно на соседнее пространство |
| Super+L | Заблокировать экран |
| Super+Escape | Меню питания |
| Super+Shift+Q | Выйти из niri с подтверждением |
| Super+N / Shift+N | Центр уведомлений / режим «Не беспокоить» |
| Super+Shift+C | История буфера обмена |
| Super+Shift+S | Интерфейс снимка области или экрана |
| Super+Shift+P | Снимок активного окна |
| Print | Снимок текущего выхода. На MacBook может потребоваться внешняя клавиатура |
| Super+Shift+T | Переключить Tokyo Night ↔ Catppuccin |
| Super+/ | Подсказка по клавишам |

niri сохраняет снимки в `~/Pictures/Screenshots/` и помещает их в буфер обмена.
Поддерживаются стандартные жесты niri. Горизонтальный свайп тремя пальцами
прокручивает колонки, вертикальный переключает пространства. Удерживайте
Super при перетаскивании левой кнопкой, чтобы переместить окно, или
правой, чтобы изменить его размер. Дополнительное
пространство создаётся по мере использования, а быстрые клавиши 1–5
привязаны к стабильным именам. [Жесты niri](https://github.com/niri-wm/niri/wiki/Gestures)

Клавиши XF86 управляют яркостью дисплея, громкостью (шаг 5%, максимум
100%), выключением звука/микрофона и MPRIS-воспроизведением. Их раскладка
на ряду F1–F12 зависит от режима Fn и драйвера. На клавиатурах Apple
PgUp/PgDn часто соответствуют Fn+↑/↓. Для устойчивых сочетаний
между раскладками проверьте фактическую карту на устройстве.

## Сочетания в приложениях

- **Thunar:** ⌘+C/X/V работают с выбранными файлами, ⌘+Z
  отменяет файловую операцию. ⌘+W закрывает вкладку, ⌘+T открывает
  вкладку, ⌘+, открывает настройки.
  Установщик обновляет эти записи в карте акселераторов и сохраняет
  остальные записи. [Действия Thunar](https://github.com/xfce-mirror/thunar/blob/master/thunar/thunar-window.c)
- **Foot:** ⌘+C/V копируют выделение и вставляют текст, ⌘+W
  закрывают текущее окно, ⌘+T открывает новое окно терминала.
  Ctrl+C по-прежнему прерывает команду. Вырезание и отмену внутри
  терминала определяет запущенная программа. [Конфигурация Foot](https://man.archlinux.org/man/foot.ini.5.en)
- **Firefox:** сочетания из доступного списка настраиваются в профиле
  через `about:keyboard`. Эту экспериментальную настройку применяют
  вручную в нужном профиле. [Справка Mozilla](https://support.mozilla.org/en-US/kb/customize-keyboard-shortcuts-firefox)
